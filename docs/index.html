Why this exists

One useful calendar for the Warsaw area.

Event details are scattered across venue sites, library calendars, tourism pages, social posts, and word of mouth. Warsaw Weekend brings those public listings into one searchable place, puts events closest to Warsaw first, and links back to the original source so details can be confirmed.
